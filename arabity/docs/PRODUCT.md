# عربيتي — ملاحظات المنتج

الهرمية: بيانات → حسابات → ملاحظات → إجراء بسيط.

التطبيق عمره ما يدّعي تشخيص ميكانيكي. درجة المتابعة بتقيم الالتزام بالتسجيل والمواعيد الإدارية بس.

الاستهلاك يتحسب تفويلة كاملة → تفويلة كاملة. تفويلة ناقصة مش بتدخل في المتوسط.

النسخ الاحتياطي هو جسر اللابتوب ↔ الموبايل. مفيش سحابة.
